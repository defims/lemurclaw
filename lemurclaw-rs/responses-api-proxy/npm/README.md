# @openai/codex-responses-api-proxy

<p align="center"><code>npm i -g @openai/codex-responses-api-proxy</code> to install <code>lemurclaw-responses-api-proxy</code></p>

This package distributes the prebuilt [lemurclaw Responses API proxy binary](https://github.com/openai/codex/tree/main/lemurclaw-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/lemurclaw-responses-api-proxy.js --help
```

Refer to [`lemurclaw-rs/responses-api-proxy/README.md`](https://github.com/openai/codex/blob/main/lemurclaw-rs/responses-api-proxy/README.md) for detailed documentation.
